# Privacy Policy - Agent Zero Gmail

Agent Zero Gmail is a personal tool used only by its owner, Ed Friedman, to access his own Gmail account.

**Data accessed:** only the owner's own Gmail data, through Google OAuth, with the permissions the owner grants.

**Use:** the data is used only to automate the owner's own email tasks.

**Sharing:** no data is sold, shared with, or disclosed to any third party.

**Storage:** OAuth tokens and any data are stored only on the owner's own devices.

**Revoking access:** access can be revoked at any time at https://myaccount.google.com/permissions
